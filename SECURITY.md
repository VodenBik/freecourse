# Security policy

## Supported release

Security fixes are currently assessed for the latest `v0.1.x` release line.

## Reporting a vulnerability

Do not publish credentials, exploit details, or personally identifiable data in a public issue. Report a suspected vulnerability privately to the repository owner with:

- affected version or commit;
- a minimal reproduction;
- impact and affected component;
- suggested mitigation, if known.

Please allow time for investigation and a coordinated fix before public disclosure. If a secret is exposed, rotate it immediately; removing it from the current branch does not invalidate it.
